# Harsh Kumar - Portfolio: Follow the Request 🚀

> An interactive developer portfolio where you become a request traveling through a distributed backend architecture.

Live Site: **[https://hk2257853.github.io](https://hk2257853.github.io)**

---

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler & Tooling:** Vite, Rolldown
- **Animations:** GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Audio:** Web Audio API (zero external audio dependency)
- **Deployment:** GitHub Actions & GitHub Pages

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build

# Preview build locally
npm run preview
```
